## How to sign

Before opening your first pull request, send an email to
fdamador@comcast.net with the subject `kronspice CLA` and this text:

```
I have read the kronspice Contributor License Agreement, version 1.0,
and I hereby sign it.

Full name:
GitHub account:
Date:
```

For an employer, the authorised representative adds the employer's legal
name, the representative's title and the list of employee GitHub
accounts to the same email.

The Project Owner confirms by reply and records Your name, GitHub account,
the date and the version of this document. Pull requests from accounts
without a signed agreement cannot be merged
([CONTRIBUTING.md](CONTRIBUTING.md)). If a CLA check is later added to
pull requests, signing by the comment it asks for has the same effect as
signing by email.
