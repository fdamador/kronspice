## How the pieces fit

```
netlist.Parse ─► circuit.FromDeck ─► circuit.Validate
                                         │
circuit.Builder (GA path) ───────────────┤
                                         ▼
                 analysis.New: device.FromCircuit → Setup (unknowns, branches)
                                         │
                 analysis.OP:  Load (stamps) → solver.Dense.Solve (LU, pivoting)
                                         │
                 output.Result: node voltages, element V/I/P, ports
                                         │
                 em.BuildLedger → element × channel rows → em.CheckLedger
```

## Conventions

- **Node 0 is ground**; `0` and `gnd` both name it. Node names are case-insensitive.
- **Element current** is measured from n+ to n− through the element. For a
  voltage source this matches ngspice's `i(vname)` (negative when the source
  delivers power).
- **Current sources** follow SPICE: `I1 a b 1m` draws 1 mA out of node `a`,
  through the source, into node `b`.
- **Ledger sign**: + means energy entering the circuit from the exterior,
  − means energy leaving it. Independent sources are Kron's impressed sources
  on the electrical exterior port; resistor heat leaves through the thermal
  port. Unmodeled ports are Kron's inactive junction pairs: exactly 0 W.
- **Residual** = inflow − outflow − dissipation − storage rate. A residual
  above 1e-9 (relative) returns `em.ErrLedgerResidual`: a bug, never a result.

`circuit.ErrNoGround`, `circuit.ErrFloatingNode`, `circuit.ErrDuplicateName`,

## Deviations from CLAUDE.md

- The dense backend is a native LU instead of gonum (CLAUDE.md §3 updated):
  the cloud workspace could not download modules, and a dependency-free core
  is simpler. A gonum backend can be added behind `solver.Matrix`.
- The `Device` interface has `Setup`, `Load`, `Operating` and
  `ExteriorPower` so far; `LoadAC`, `Converged` and `Truncate` arrive with
  AC (M3), Newton (M4) and transient (M2).
