## What was added

- **Elements:** capacitor (`C name n1 n2 value [IC=v]`) and inductor
  (`L name n1 n2 value [IC=i]`), each with the full external port set.
- **Sources:** `DC`, `AC mag [phase]` (stored for M3), `PULSE`, `SIN`,
  `EXP`, `PWL`, in any order and with or without parentheses and commas.
  Missing arguments take the SPICE3 defaults (e.g. PULSE rise/fall = tstep).
- **`.tran tstep tstop [tstart [tmax]] [uic]`.**
- **Transient engine** (`analysis/tran.go`):
  - operating point at t = 0 (or initial conditions with UIC);
  - backward Euler for the first step and after every breakpoint,
    trapezoidal otherwise (or backward Euler everywhere by option);
  - step size from the local truncation error of every capacitor charge and
    inductor flux (divided differences, SPICE-style tolerances: reltol 1e-3,
    abstol 1e-12 A, vntol 1e-6 V, chgtol 1e-14, trtol 7);
  - exact landing on every source breakpoint (PULSE edges, PWL corners, SIN
    delay, EXP times);
  - guards: `ErrTimestepTooSmall`, `ErrTooManySteps`, `ErrBadTranSpec`.
- **Transient ledger** (`output.TranLedger`): inflow, outflow, dissipation,
  storage rate and stored energy at every time point; energies integrated
  over the run; the integration mismatch (time-stepping error) reported
  separately from physical channels.
- **Output:** `output.Waveforms` with `NodeVoltage`, `ElementCurrent` and
  `Interp`; CSV resampled on the print step; a transient summary report.
- **CLI:** runs `.op` and `.tran` as requested by the netlist.

## Notable checks

- **LC oscillator (UIC):** stored energy stays within 0.1 % over 10 periods
  with trapezoidal integration (no numerical damping). The phase drifts by
  about 5e-4 of a period per period at default tolerances — expected for
  the trapezoidal rule.
- **Backward Euler on the same LC:** loses energy, and the ledger reports
  the loss as integration mismatch, never as dissipation. Numerical artifacts
  must never look like physics (CLAUDE.md §1, vision rule 4).
- **Fuzzing:** the parser fuzzer found and fixed one crash (a line holding
  only `(`); the input is kept as a regression test. A new full-pipeline
  fuzzer (parse → validate → `.op`/`.tran`) ran 1.3 million inputs with no
  failures.

## Deviations and notes

- Gear-2 integration is not implemented yet (listed as an option in
  CLAUDE.md §3); backward Euler and trapezoidal are.
- UIC reports the t = 0 point by pinning each capacitor to its IC with a
  1e9 S Norton equivalent and each inductor current to its IC; that imposed
  point is excluded from the residual check.
- `Device` now has `Accept` (commit a solution); reactive devices add
  `StoredEnergy` and `Truncate`; sources add `NextBreakpoint`.
